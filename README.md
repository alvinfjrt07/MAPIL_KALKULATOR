# MAPIL KALKULATOR

## Deskripsi
MAPIL Kalkulator adalah aplikasi kalkulator sederhana berbasis web
yang dibuat untuk membantu melakukan perhitungan matematika,
konversi mata uang, dan menghitung BMI.

## Fitur

### 1. Kalkulator
- Penjumlahan (+)
- Pengurangan (-)
- Perkalian (×)
- Pembagian (÷)
- Persentase (%)
- Positif/negatif (+/-)
- Angka desimal
- Clear (AC)
- Validasi pembagian dengan 0

### 2. Pengonversi
- Konversi mata uang USD ke IDR
- Menampilkan hasil konversi secara otomatis

### 3. BMI
- Input tinggi badan
- Input berat badan
- Menghitung nilai BMI
- Menampilkan kategori BMI

## Cara Menjalankan

1. Clone repository MAPIL_KALKULATOR.
2. Buka folder project menggunakan Visual Studio Code.
3. Buka file `index.html`.
4. Jalankan menggunakan Live Server.
5. Aplikasi akan terbuka di browser.

## Desain UI/UX
